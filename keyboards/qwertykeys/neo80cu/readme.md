# Neo80 Cu

Wired firmware definition for the Qwertykeys Neo80 Cu, rebuilt from the vendor `tab_neo_neo80_cu_072_via_20250815.bin` and the VIA JSON.

* Keyboard Maintainer: xoppel
* Hardware: STM32F072, stm32-dfu bootloader, WS2812 RGB on B3 (16 LEDs)
* Layouts: `LAYOUT_ansi[_split_bs][_split_lshift][_7u]`

Make example for this keyboard (after setting up your build environment):

    make qwertykeys/neo80cu:xoppel
